# Toyota Altezza AS200 1G-FE BEAMS (3D)

Interactive procedural 3D model of the 1G-FE BEAMS 2.0 L straight-six. Open index.html via GitHub Pages.

Figures marked as estimates in the page are approximate. Published specs: 75.0 x 75.0 mm, firing order 1-5-3-6-2-4, 160 PS @ 6,200 rpm, 200 N.m @ 4,400 rpm.
